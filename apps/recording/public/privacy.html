一歩の記録へ戻る

データの扱い・プライバシーポリシー

対象：一歩の記録 / Ippo Recording Session v0.2
更新日：2026年10月23日

一歩の記録は、招待された二人の通話を、双方の同意に基づいて二人の声を一つの会話音声に録音し、収集チームのGoogle Driveへ保存するアプリです。

収集する情報と目的

表示名、通話・録音の識別子、対話のタイトル、二人の声を混合した会話音声、録音日時、同意の版・日時、録音の停止理由、保存したDriveファイルの識別子を扱います。通話の接続、同意確認、録音、保存と再送のために使用します。

録音は双方が録音とDrive保存に同意した場合だけ開始できます。同意の取り消し、接続・音声処理の中断などで録音を停止します。画面の切り替えだけでは録音や通話を停止せず、正常な録音は画面へ戻った後も継続します。OSやブラウザーが音声処理を止めた場合、未録音区間を復元することはできません。取り消し後も、それまでに保存した原本が自動的に削除されるわけではありません。

音声の保存先と閲覧できる人

音声は通話作成者の端末に一時保存し、接続済みの収集チームのDriveフォルダへ送信します。閲覧できる人はDriveの共有権限によって決まります。収集担当者は、保存先を収集メンバーだけがアクセスできる範囲に設定してください。

原本の保存期間、後日のWindowsでの文字起こし・人手校正の対象と利用目的は、招待した収集担当者が案内します。このアプリは文字起こし・AI分析・共通知識への登録を自動実行しません。録音への同意に、それらのAI利用許可は含まれません。

連絡先からの呼び出し（有効な環境のみ）

電話帳の名前・並び順・相手の公開鍵と自分の秘密鍵は端末内に保存します。中央にはランダムな鍵から作った利用者ID・端末ID・公開鍵・端末の承認情報・通知先・相手との呼び出し許可を保存します。電話帳のメールアドレス・電話番号・名前の一覧は中央に収集しません。ただしIDや通知先も利用者に結び付く情報です。

相手との登録はLINEなどで送った10分有効のリンクと双方の確認コード照合で行います。表示名はリンク内の情報として相手とLINEなどの共有先へ渡ります。端末追加時の電話帳は暗号化して中央を経由し、追加する端末で復号します。登録中の暗号文は10分、呼び出しメタデータは最大24時間保持します。登録・承認・解除情報は中央の運用に必要な間保持します。

通知サービスはApple・Google・Mozillaなどを利用し、通知の内容に名前・録音・通話参加資格情報を含めません。同じ人の複数端末に通知し、応答した1台だけが通話へ参加できます。通知が必ず届く保証はありません。端末の解除はアプリの登録端末一覧から行えます。サイトデータを削除すると電話帳と鍵が失われるため、別端末の追加を先に行ってください。

Googleアカウントへのアクセス

Google連携を行うのは収集担当者です。通話参加者はGoogleへログインせず、招待リンクで参加できます。担当者はGoogleのフォルダ選択画面で保存先を選び、アプリが選択済みのフォルダやアプリで作成したファイルを扱うための権限（drive.file）を許可します。Drive全体へのアクセス権限は要求しません。

接続時にフォルダ名・種類・ファイル追加権限を確認し、保存時にアプリが作成したファイルの識別子・サイズ・照合情報を確認します。これらは保存先の確認と、送信の再開・重複防止のために使用します。Googleから取得する情報を広告やAIモデルの学習のために使用したり、販売したりしません。

クライアント秘密値と継続接続用トークンは収集担当者のPCとVercelの非公開設定で管理します。認証とフォルダ選択はGoogleの画面で行い、短期アクセストークンや継続接続用トークンを担当者のローカル接続画面へ返しません。通話参加者には、固定の保存先へ送信するための限定されたアップロードURLを発行します。Googleの汎用アクセストークンや継続接続用トークンは渡しません。

Google APIから取得した情報は、Google API Services User Data PolicyのLimited Use要件に従って扱います。担当者はGoogleアカウントの接続管理で許可を取り消せます。取り消すと今後のDrive保存はできなくなりますが、保存済みファイルはDriveに残ります。

利用するサービスと通信

アプリとAPIはVercelで実行します。二者の音声はWebRTCで直接送受信し、直接接続が難しい場合や経路を変更する場合にCloudflare TURNを利用します。接続・同意状態の管理にはCloudflare Workerを使用します。通話の状態は最長2時間で失効・削除します。音声原本の保存先はGoogle Driveです。

各サービスは通信の提供や障害対応のため、IPアドレスなどの通信情報を処理することがあります。画面の書体の取得にはGoogle Fontsを利用します。音声をVercelや接続管理Workerで録音する処理はありません。

端末保存・削除・問い合わせ

端末の録音コピーは、アプリ内で手動削除するまで残ります。端末のコピーを削除してもDriveの原本は削除されません。中断した録音は自動送信せず、端末での確認を求めます。共有端末では保存済みであることを確認してから端末コピーを削除してください。

原本の削除、返却、保存期間、利用目的に関する問い合わせは、通話に招待した収集担当者へ連絡してください。この公開版を配置する運用者は、公開前に問い合わせ先と実際の保存・削除方針を設定してください。
